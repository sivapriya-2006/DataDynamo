# Day 9 – Identify Incorrect Queries and Responses

## Objective

Identify incorrect, unclear, unsupported, and challenging natural-language queries and responses from the grid assistant.

## Completed Tasks

- Created challenging natural-language queries.
- Tested unsupported queries.
- Tested missing-region queries.
- Tested unknown-region queries.
- Tested unsupported telemetry fields.
- Tested future-date queries.
- Tested historical-date queries.
- Tested alternative terminology.
- Identified system limitations.
- Categorized problematic queries.
- Created an issue summary.
- Saved the analysis results as CSV files.

## Output Files

- `Data_Dynamo_Day_9.ipynb`
- `day9_incorrect_queries_analysis.csv`
- `day9_issue_summary.csv`

## Day 9 Outcome

The testing identified limitations in the current natural-language grid assistant. These findings will be used to improve query processing, intent detection, and prompt design in the following stages.
