# Day 1 – Power Consumption Forecasting

## Objective

Develop the initial power-consumption forecasting model and define the natural-language telemetry workflow.

## Work Planned

- Generate hourly regional power telemetry data.
- Create data for multiple regions.
- Add temperature and time-based features.
- Create lag and rolling-average features.
- Train a forecasting model.
- Evaluate the model using MAE and RMSE.
- Visualize actual vs predicted power consumption.
- Define the initial natural-language telemetry workflow.
